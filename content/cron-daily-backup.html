Cron: Nightly Backup & Maintenance Jobs

The classic nightly backup cron: 0 2 * * * with flock locking, log capture, retention pruning and the 2 AM myth.

0 2 * * *

The classic nightly slot: 02:00 every day. For real backup jobs, three additions turn a fragile line into a reliable one.

The production pattern

0 2 * * * flock -n /tmp/backup.lock /usr/local/bin/backup.sh >> /var/log/backup.log 2>&1

PieceWhy
flock -nprevents overlapping runs when a backup exceeds 24h or is manually retried
log capturecron errors get emailed into a black hole — log to a file instead
absolute pathscron PATH is minimal — scripts and tools need full paths

Retention pruning

Backups without retention fill disks. Add a second job: 0 3 * * * find /backups -mtime +14 -delete keeps a 14-day window.

The 2 AM myth

Everyone schedules at 2 AM — making it the most contended slot on shared systems. On your own box it does not matter; on shared hosting, pick an odd minute (17 2 * * *).
